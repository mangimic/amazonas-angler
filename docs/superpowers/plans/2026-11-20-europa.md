# Europa freischalten – Bauplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 5 neue Angelplätze in 5 Ländern (Schweiz, Niederlande, Österreich, Ungarn, Tschechien), freischaltbar über Fluss-Stempel, mit eigener Europa-Karte (NEWS v45).

**Architecture:** Alles in `index.html`. Die Auslands-Plätze werden **am Ende** von `SPOTS` angehängt und haben `land` statt `bl` (neue Tabelle `LAENDER`). Eine Hilfsfunktion `ortVon(s)` liefert für jeden Platz die Texte „Bundesland/Land“ und „Landeshauptstadt/Hauptstadt“; alle Stellen, die heute `BL[s.bl]` lesen, nutzen sie. Alles, was nur Deutschland meint, filtert mit `deSpots()`. Neue `LINKS` schalten frei. Eine zweite Karte `showEuropa(mode)` zeichnet `EUMAP` (vorbereitete Natural-Earth-Daten).

**Tech Stack:** eine HTML-Datei, Three.js r128 (global `THREE`), Canvas 2D für Karten, Tests mit node:test + Playwright in `tests/spielstand.test.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-20-europa-design.md`

## Global Constraints
- Alle Texte Deutsch, kurz, für Kinder von 7–9 Jahren. Fakten müssen stimmen; jede Tatsache aus Tafel, Rätsel und Fischliste bekommt eine Quelle in `docs/fakten-quellen.md` (Stil und Prüfung: Skill `.claude/skills/sachkunde-grundschule`).
- Neue Platz-`id`s (fest ab jetzt): `ch-rhein`, `nl-rhein`, `at-donau`, `hu-donau`, `cz-moldau`. Länder-Schlüssel in `LAENDER`: `ch`, `nl`, `at`, `hu`, `cz`.
- `LAENDER={ch:{name:'Schweiz',hs:'Bern'},nl:{name:'Niederlande',hs:'Amsterdam'},at:{name:'Österreich',hs:'Wien'},hu:{name:'Ungarn',hs:'Budapest'},cz:{name:'Tschechien',hs:'Prag'}}` (weitere Felder für die Karte erlaubt).
- **Neue Plätze nur am Ende von `SPOTS` anhängen**: `buildSpot` nutzt `rng(9000+SPOTS.indexOf(s)*131)`; die Reihenfolge der alten 18 darf sich nie ändern.
- Keine neuen Fischarten, keine neuen Fotos. `fish` nur mit vorhandenen `FISH`-ids.
- `SAVE_VERSION` bleibt 2, kein neues Spielstand-Feld, kein Schlüssel ändert sich.
- Nichts zur Laufzeit aus dem Internet laden. Karten-Daten als Konstante `EUMAP` in `index.html`.
- Knöpfe ≥ 60 px. Wahrzeichen sanft und kindgerecht (r128-Lichtwerte wie die vorhandenen Looks).
- Texte aus Daten nur mit `esc()` ins HTML.
- Tests: Zeit nie mit `ctx.clock.setFixedTime`; jede Seite `ctx.close()`, `errors` leer. Vor jedem Commit `cd tests && npm test` (alle grün; ~30 min), beim Arbeiten nur gezielte Tests (`--test-name-pattern`).
